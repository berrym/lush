#Known intentional divergences from the reference shell.
#Format : < basename> < reason>
#Each entry documents a case where lush's output deliberately differs
#from the reference shell for a principled reason.diff_oracle treats
#allow - listed divergences as expected : the JSONL record still shows
#them but they do not contribute to the unexpected - divergence count.

052_zsh_assoc_array.sh  Insertion-order iteration of associative arrays via libhashtable's ht_enum_t is a deliberate polyglot choice; zsh's hash-bucket order is implementation-detail and unspecified by spec. Explicit ordering via ${(ko)hash} / ${(kO)hash} (sorted and reverse-sorted) is already wired for scripts that need a deterministic order.

301_zsh_param_sort.sh  zsh's parameter-flag context-sensitivity is a deliberate non-implementation in lush. zsh treats "${(o)arr}" (quoted) as scalar context and skips sorting, while ${(o)arr} (unquoted) sorts. lush sorts uniformly in both contexts, which is simpler, more useful, and matches user expectation; the zsh quirk requires per-call quote-context tracking through the expansion pipeline and is a behavioral footgun that few scripts depend on. Scripts that need original-order can simply omit the sort flag.

307_zsh_array_iter.sh  Similar context-sensitivity divergence: zsh's ${(Oa)arr} (reverse-anchored) in unquoted for-loop position produces N words for iteration; in quoted/scalar context it produces a joined string. lush emits the joined string uniformly. The for-loop-as-vector behavior is recoverable via ${arr[@]} which IS treated as a vector in unquoted argv/iteration positions; ${(Oa)} expressly is not needed for iteration when ${arr[@]} is available.

314_zsh_param_uniq.sh  Same context-sensitivity family as 301 / 307: zsh's ${(u)arr} / ${(uo)arr} in quoted context skip array-typed flags (scalar context), while unquoted they apply uniqueness and sort. lush always applies the flags. The corpus uses "${(uo)dups}" -- quoted -- so lush dedups+sorts while zsh emits the original. Both behaviors are spec-defensible; lush's is more useful since "always apply requested transformation" is least surprising. Scripts that need zsh's quoted-skip behavior should drop the parameter flags entirely.
