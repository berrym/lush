# bucket as not-covered rather than false-passing on a partially-consumed line.

# Mid-word $'...' (pre$'\t') is ANSI-C the live executor decodes in place, but
# the tokenizer returns it as one bare WORD; the CST defers it (NOT-COVERED)
# rather than mis-decode -- decoding mid-word ANSI-C is a later slice.
pre$'\t'
# Excluded (no parity signal through the printf/for transport, which truncates
# at NUL; the char* leaf also cannot carry a length -- documented limitation):
#   $'\0'  $'a\x00b'
# Deferred to a fast follow-up (multi-byte UTF-8 output, locale-sensitivity to
# verify end-to-end before claiming parity):

# Parameter-expansion operators. wordtool evaluates these through the SAME
# shared core as live lush (lush_param_op_apply, src/param_op.c), so glob
# patterns, the #/% substitution anchors and grapheme-aware substrings are all
# real parity signal rather than a bench approximation (issue #681).
${Y:-def}
${E:-def}
${UNSET:-def}
${Y:+alt}
${E:+alt}
${UNSET-d}
${E+a}
${Y#c}
${Y##?}
${Y%d}
${Y%%?}
# The next three carry a SPACE in the pattern operand, which parse_word
# cannot represent -- they bucket as NOT-COVERED and are here to pin that
# boundary, not to assert a value.
"${X#* }"
"${X##* }"
"${X%% *}"
${Y^^}
${Y^}
${Y,,}
"${X^^}"
${U^^}
${U,,}
${Y:0:1}
${Y:1}
"${X:2:3}"
${U:0:3}
${U:3}
${U:3:1}
${Y/c/Z}
${Y//c/Z}
${Y//?/Z}
${Y/c*/Z}
${Y/%*/Z}
${U/é/e}
# NOTE: ${U//?/.} yields 5 fields' worth of dots, not 4 -- the pattern
# scanners match single BYTES and split the multi-byte character (#682). The
# line is still valid parity signal (the bar is wordtool == lush, and both run
# the same shared core), and it will keep passing when #682 is fixed.
${U//?/.}
${Y/zz/Q}
${Y//c/}
# The assign operators are the one covered family with a SIDE EFFECT: wordtool
# models the write-back with setenv (its variable store is the environment), so
# a line that observes the assignment is real parity signal. word_diff runs one
# process per line per shell, so the writes do not leak between lines.
${A1:=set}
${A2=set}
${Y:=other}
${E:=filled}
${E=kept}
${A3:=}
# These OBSERVE the write-back within the same word, which is what makes the
# bench's setenv model (and lush's pending-write buffer) real parity signal
# rather than an untested claim.
${A4:=v}${A4}
${A5}${A5:=w}
"${A6:=q}${A6}"
${E:=z}${E}
# The required-parameter operators are covered only where the diagnostic does
# NOT fire (a firing one defers so the legacy expander owns the error and the
# POSIX exit). The message is captured RAW, so spaces and glob metacharacters
# in it are covered -- these lines are the parity signal for that, since a
# tokenized operand would drop the spaces. A message carrying a QUOTING byte
# (quote, backtick, backslash) or a `$` DEFERS, so no such line appears here.
${X:?msg}
${Y?msg}
${Y:?}
${Y?}
${Y:?must be set}
${Y:?a-b+c*d}
${E?empty is set}
"${Y:?a}b"
${Y:?a}${Y?b}
# A backtick is an expansion introducer inside a double-quoted string, not a
# literal byte. Covering it as a literal made `echo "date: `date`"` emit its own
# source text on the default route (#693). It survived because no corpus line
# and no test contained one -- which is the point of this line: word_diff
# compares against the LEGACY expander, so a re-cover would show up as a BUG
# verdict rather than as silence.
"[`echo H`]"
"pre`echo H`post"
"$X`echo H`"

# Case conversion with a RESTRICTING pattern (#683). The pattern selects which
# characters convert; it is recovered literally and matched by the same
# lush_case_pattern on both routes. Y="cd" and U="café" exercise an ASCII and a
# non-ASCII pattern; a class is written non-leading because an operand starting
# with `[` re-tokenizes as the `[` builtin and defers at parse.
"${Y^^c}"
"${Y^^x[cd]}"
"${Y,,C}"
"${Y^c}"
"${Y^d}"
"${U^^é}"
"${U^^*}"
